# StepMania Chart Viewer
(SM File DDR Chart Renderer [Wiki Style Pro])
https://yoppyy.github.io/StepManiaChartViewer/

StepManiaの譜面ファイル（`.sm`）を読み込み、DDR（DanceDanceRevolution）のナビゲーションWiki等でおなじみの「縦スクロール形式」に変換して、高解像度な一枚の画像としてレンダリング・保存できるWebアプリケーションです。

HTMLファイル1本で完結しているため、サーバーを用意することなくブラウザ上で即座に動作します。

## 🌟 主な機能と特徴

- **1マイルストーン完結型**: 外部サーバーやデータベース、追加ライブラリ（npm等）への依存はなく、ブラウザの標準Canvas APIのみで高速に描画します。
- **SP / DP 完全対応**: Single Play（4レーン）、Double Play（8レーン）の双方を自動判別して最適な幅でレンダリングします。
- **2倍引き伸ばし＆8分割表示（新機能）**: 「1小節を2倍に伸ばす」オプションを有効にすると、1小節の高さが2倍に広がり、各拍の中間に16分音符のガイドとなる **8分割の点線（0.5拍単位）** が表示されます。超高密度譜面や縦連、ハネたリズムの視認性が大幅に向上します。
- **配置タイプ切り替え**: 
  - **タイプA (中心合わせ)**: 矢印の中心が拍の区切り線（ビートライン）に重なる配置です。
  - **タイプB (上端合わせ)**: 矢印の上端が区切り線にぴったり揃う配置です。
- **スマート・レイアウト**: 
  - 1列あたりの表示小節数（8, 10, 12, 14, 16小節、または全小節1列）を自由に調整可能。
  - レーン間や列の間隔を限界まで最適化（列の隙間: 60px）し、横スクロールを抑えたコンパクトな設計。
- **BPM / STOP 変更の可視化**: 譜面内で変化するBPMやSTOP（フリーズ）情報を、発生した拍の位置へ正確に（小数点第3位まで）自動描画します。
- **ダークモード搭載**: 明るい部屋や夜間など、環境に合わせてワンクリックでライト/ダークの配色テーマを切り替えられます。
- **高画質画像保存**: 生成された譜面は、楽曲タイトルや難易度、ノーツ数などの統計データを含めて、そのまま透過PNG画像としてワンクリックでローカルにダウンロード・保存できます。

## 🚀 使い方

1. 本リポジトリの `index.html`（または作成したHTMLファイル）をダブルクリックし、Google ChromeやMicrosoft Edge、Safariなどのブラウザで開きます。
2. 画面上部の「`.smファイル:`」の横にある「ファイルを選択」ボタンを押し、お手持ちの `.sm` 譜面ファイルを読み込ませます。
3. ファイルが正常に読み込まれると、タイトルやアーティスト名が自動反映され、「譜面:」のセレクトボックスから難易度（Challenge, Expert, Difficult等）を選択できるようになります。
4. お好みに合わせて「1列の小節数」「1小節を2倍に伸ばす（8分割点線）」「矢印の配置」「ダークモード」などの各種設定を調整します。
5. 「画像として保存」ボタンを押すと、自動的に適切なファイル名（`[楽曲名]_[SP/DP]_[難易度].png`）が生成され、高解像度なPNG画像がダウンロードされます。

## 🛠️ 技術仕様・カスタマイズ

内部のスタイルシート（CSS）にて以下の変数（CSS変数）を定義しているため、お好みの色合いに簡単にカスタムできます。

```css
:root {
    --bg-color: #f7f7f7;       /* 全体背景（ライト） */
    --text-color: #000000;     /* 文字色 */
    --lane-bg-even: #dcdcdc;   /* 偶数拍のレーン背景 */
    --lane-bg-odd: #ffffff;    /* 奇数拍のレーン背景 */
    --grid-line: #888888;      /* 4分拍・小節の区切り線 */
    --grid-sub-line: #aaaaaa;  /* 8分割の補助点線（2倍化時） */
}
